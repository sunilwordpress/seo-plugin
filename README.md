Advanced Simple SEO Plugin
 
An SEO plugin is a tool that integrates with a website’s CMS to help improve its search engine optimization. By automating and assisting with tasks such as managing meta tags, generating sitemaps, handling redirects, providing analytics, and optimizing content, SEO plugins make it easier for website owners to boost their site’s visibility and ranking on search engines. These plugins are essential for improving on-page and technical SEO, making the process more efficient and accessible to both beginners and experienced users.

General:
•	Website Name
The Website Name or Site Title is a general name for your website, often reflecting your brand, business, or blog name.

 

•	Tagline
The tagline is a brief slogan or description associated with your WordPress site, typically displayed alongside or below the Site Title. It is meant to give visitors a quick understanding of what your site is about.

 

•	Title separator
The Title Separator is a character or symbol used to separate different elements in the title tag of your site's pages. This separator is primarily used in the SEO meta titles that appear in browser tabs, search engine results, and other contexts where the title is displayed.

 
•	Site image	
This image is used as a fallback for posts/pages feature image that don’t have any images set.

 





Meta:
•	Default Meta Title	
The default meta title is the fallback title that WordPress or an SEO plugin assigns to a page when a specific meta title isn't manually defined. It typically includes elements like the page name, site title, and sometimes a separator.

 

•	Default Meta Description		
The default meta description is an automatically generated or predefined description that is used when a custom description has not been set for a specific page or post. It aims to provide a concise summary of the content for users and search engines.

Sitemap:
•	Open AI Key/Secret key	
A sitemap is a structured list or map of all the pages, posts, and other significant content of a website. It is primarily used by search engines to index a website's content and improve crawling efficiency, ensuring that all relevant pages are included in search engine results.

 

•	Sitemap Post Types		
In a sitemap, post types refer to the different types of content on your website, such as blog posts, pages, and custom post types. Each type of content can be included in the sitemap, which helps search engines discover and index all important pages on your website.

Crawl:
•	Remove unwanted metadata
WordPress adds a lot of links and content to your sites and HTTP headers. For most websites you can safely disable all of these, which can help to save bytes, electricity, and trees.

 

•	Disable unwanted content formats
WordPress outputs your content in many different formats, across many different URLs (like RSS feeds of your posts and categories). It’s generally good practice to disable the formats you’re not actively using.

 

•	Remove unused resources	
WordPress loads lots of resources, some of which your site might not need. If you’re not using these, removing them can speed up your pages and save resources.

Redirection:
•	301 Redirect (Permanent Redirect):
A 301 redirect signals that the requested URL has been permanently moved to a new location.
•	302 Redirect (Temporary Redirect):
A 302 redirect indicates that the requested URL is temporarily redirected to a different URL, but the original URL will be used again in the future.

 
•	Delete Redirect
Using the Delete button, you will remove your redirect links.

•	Canonical URL
A Canonical URL is an HTML element used to specify the preferred version of a webpage when duplicate or similar content exists across multiple URLs. It helps search engines understand which page should be ranked and credited with link equity, improving SEO by preventing issues related to duplicate content.
